AstrBot SD Prompt 插件（通用LLM版）

这是一个用于 AstrBot + Stable Diffusion 的绘图插件
支持 中文转提示词 + AI翻译 + 本地词库 + 自动出图

--------------------------------------------------

【功能特点】

- 中文自动转 Stable Diffusion 英文提示词
- 支持任意大模型（豆包 / OpenAI / DeepSeek / 本地）
- 自动调用 SD WebUI 出图
- 所有配置在配置页完成（不用改代码）
- 不填 API 也能用（本地词库兜底）
- 自动清理历史图片

--------------------------------------------------

【安装方法】

1、确保已安装astrbot
2、将插件复制到 AstrBot 的插件目录
3、重启 AstrBot

--------------------------------------------------

【配置说明】

打开 AstrBot 插件配置页，填写：

一、LLM配置（可选）

API_KEY     填你的模型key（不填就不用AI）
API_BASE    接口地址
MODEL_NAME  模型名称

示例：

API_BASE=https://ark.cn-beijing.volces.com/api/v3
MODEL_NAME=doubao-seed-2-0-mini-260215

--------------------------------------------------

二、Stable Diffusion配置（必须）

SD_API_URL  填你的SD接口地址

默认：

http://127.0.0.1:7860/sdapi/v1/txt2img

--------------------------------------------------

【使用方法】

直接输入：

绘图 可爱双马尾洛丽塔少女坐在教室里

也可以中英混合：

绘图 cute girl sitting in classroom

也支持负面词：

绘图 少女在教室 --neg low quality, bad hands

--------------------------------------------------

【工作流程】

输入描述
→ AI翻译（如果配置了）
→ 本地词库补充
→ 生成提示词
→ 调用SD生成图片

--------------------------------------------------

【注意事项】

1、必须开启SD接口

启动WebUI时加参数：

--api

--------------------------------------------------

2、常见问题

无法出图：
- 检查SD是否启动
- 检查SD地址是否正确

AI不生效：
- 是否填写API_KEY
- 接口是否支持 chat/completions

报错但图发出来了：
- 一般是发送超时，可以忽略

--------------------------------------------------

【自动清理】

- 每小时检查一次
- 自动删除3天前的图片

--------------------------------------------------

【支持的模型】

只要支持以下接口就能用：

POST /chat/completions

例如：
- 豆包
- OpenAI
- DeepSeek
- 本地模型（Ollama）

--------------------------------------------------

这是一个轻量级提示词生成 + SD绘图插件
可以自由更换模型和接口
